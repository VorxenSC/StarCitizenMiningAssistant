# test_images

Screenshots for offline regression testing — no Star Citizen needed.

## Naming

Put the expected RS in the file name as `rs<NUMBER>`:

```
gold-x3__rs10755.png
my_capture_2026-10-01__rs3870.png
```

Files without `rs<NUMBER>` are skipped by `regress` (but can still be run with `analyze`).

## ROI profile

If a folder contains `profile.roi.json`, every image in it is cropped to the RS region of that
profile before OCR — exactly like the live overlay does. Copy your calibrated profile from
`config/profiles/default.roi.json` (next to the app) into the folder with your real screenshots.
Without a profile the whole image is OCR'd (slower and less reliable).

## Run

```
mining-cli regress test_images        # all folders
mining-cli regress test_images -v     # print passing files too
mining-cli analyze test_images/real/foo__rs3585.png
```

`synthetic/` is generated by `mining-cli synth` (HUD-like renders with several fonts/colors).
Add real in-game screenshots under `real/` — they are far more valuable than synthetic ones.
