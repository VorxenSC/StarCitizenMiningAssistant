# contributions/

Older signature contributions (v0.1.1–v0.1.7 sent them here with the GitHub CLI; that path was removed).

Since v0.1.8, players share signatures **by hand** from the app (*Advanced settings*):
- **Share on Discord (copy)** — a ready-to-paste text;
- **Share on GitHub…** — a pre-filled issue in the public downloads repository
  [VorxenSC/MiningAssistant](https://github.com/VorxenSC/MiningAssistant/issues), with a table of
  RS seen, name, count, base RS, type, game version, date and notes (plate image optional, attached by the player).

To fold confirmed entries into the shipped database, add them to `data/<version>/materials.json`
(check `baseRS` against other reports first: one sighting can be a mixed cluster).
